RxJS Autocomplete

The box waits until you've stopped typing for 300 ms before searching (debounceTime), and a new search cancels the previous request (switchMap). Results are cached per term (shareReplay), so searching the same thing again doesn't call the server, and failed requests are retried twice (retry). Use the sliders to slow the network down or make requests fail, and watch what happens in the log.
