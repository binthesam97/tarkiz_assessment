Rendering 10,000 Records

Rendering all 10,000 rows took 3–4 seconds. This is how I got it down to tens of milliseconds:

  • Virtual scrolling, so only the rows on screen are rendered.
  • OnPush change detection, so rows only re-render when their data changes.
  • trackBy on the employee id, so sorting reuses rows instead of recreating them.
  • Memoised filtering and sorting with computed(), plus pure pipes for formatting.
  • Lazy loading, so this page's code is only downloaded when you open it.
